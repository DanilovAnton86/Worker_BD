# Учёт сотрудников колл-центра

Эта программа хранит список сотрудников: имена, телефоны, пароли, проекты
и локации. Список можно открыть в браузере. Там же можно искать людей
и менять данные.

Программа работает и на Windows, и на Linux.

---

## Два разных запуска

Не путайте эти два файла:

| Файл | Когда запускать | Что делает |
| --- | --- | --- |
| `install.py` | один раз, при первом запуске на новом компьютере | Помогает заполнить настройки, проверяет всё и при желании создаёт базу и загружает данные |
| `launcher.py` | каждый день | Обновляет данные и управляет сайтом. Сайт работает в фоне, меню остаётся открытым |

Обновлять данные из общего списка и из Excel можно прямо при работающем сайте.
Останавливать сайт для этого не нужно.

---

## Подготовка

### 1. Установите нужные библиотеки

В папке программы есть файл `requirements.txt`.

На Windows откройте командную строку в папке программы и выполните:

```
python -m pip install -r requirements.txt
```

На Linux:

```
python3 -m pip install -r requirements.txt
```

### 2. Проверьте файлы рядом с программой

Должны лежать:

- `config.example.ini` — образец настроек;
- `for_db.xlsx` — файл с паролями;
- папка `templates` — страницы сайта.

---

## Первый запуск

Запустите установку.

На Windows можно просто щёлкнуть `start.bat` с командой `install`.
Или выполнить в командной строке:

```
python install.py
```

На Linux:

```
./start.sh install
```

Мастер задаст вопросы по очереди. Если нажать просто Enter, останется
значение из образца. Почти везде так и надо делать. Исключение — пароли
и адреса: их нужно заполнить своими.

Секретное слово для входа мастер придумает сам, если оставить образец.

Потом мастер покажет проверку:

- есть ли база данных;
- доступен ли общий список сотрудников;
- читается ли Excel-файл;
- открываются ли страницы сайта.

После проверки мастер спросит, что сделать сейчас:

```
1. Создать базу данных и таблицы
2. Сверить список сотрудников
3. Загрузить пароли из Excel
4. Всё по порядку
0. Только проверить настройки, ничего не менять
```

Если база ещё не создана, мастер сначала создаст её сам.

Повторный запуск установки ничего не портит. Уже записанные люди остаются.

## Ежедневная работа

Запустите меню.

На Windows: `start.bat` без аргументов или `python launcher.py`.
На Linux: `./start.sh` или `python3 launcher.py`.

На экране:

```
1. Обновить данные из AD
2. Загрузить пароли из Excel
3. Запустить сайт
4. Остановить сайт
5. Перезапустить сайт
6. Проверить настройки
0. Выход
```

### Что делает каждый пункт

**1. Обновить данные из AD.** Сверяет наш список с общим списком сотрудников
компании. Новых добавляет, уволенных помечает как уволенных. Их проекты
и локации остаются прежними. Если что-то непонятно, создаётся файл
`unmapped_users.txt`.

**2. Загрузить пароли из Excel.** Берёт пароли из `for_db.xlsx`. Сверяет логин
и имя с фамилией. Если не совпало, пароль не меняется, а запись попадает
в отчёт.

**3. Запустить сайт.** Сайт открывается в фоне, и меню снова готово к работе.
Адрес выводится на экране, обычно `http://127.0.0.1:8080` или
`http://0.0.0.0:8080`.

**4. Остановить сайт.** Останавливает только тот сайт, который запустили
из этого меню.

**5. Перезапустить сайт.** Сначала останавливает, потом запускает снова.

**6. Проверить настройки.** Показывает, что работает, а что нужно поправить.

Перед пунктами 1 и 2 программа сохраняет копию базы в папку `backups`.
Если две копии обновить одновременно, вторая дождётся своей очереди:
программа не даёт двум обновлениям идти в один момент.

Всё, что происходит, записывается в файл `logs/operations.log`.
Работу сайта можно посмотреть в `logs/web.log`.

## Работа в браузере

### Вход

Откройте адрес из настроек. Введите логин и пароль.
Обычные операторы на сайт не входят.

### Поиск

Наверху есть поля для поиска. Можно ввести фамилию или логин.
Рядом можно выбрать статус, проект, локацию и дату.

Как только вы меняете фильтр, список начинается с первой страницы.
Это сделано намеренно: так вы не попадёте на пустую страницу.

### Страницы

Под списком есть стрелки и кнопки «В начало», «Назад», «Вперед», «В конец».
Можно ввести номер страницы в маленьком окне и нажать Enter.
Число строк на странице меняется списком «Строк».

### Карточка сотрудника

Нажмите значок глаза в строке. Откроется карточка с телефоном, датой рождения,
проектами, локациями и паролями.

### Кто что может делать

| Кто | Что видит | Что может менять |
| --- | --- | --- |
| Оператор (OP) | — | На сайт не входит |
| Старший (ST) | только операторов | ничего, только смотрит |
| Тренер (TR) | операторов и старших | ничего, только смотрит |
| Старший смены (SV) | всех младше себя на своём проекте | операторов, старших и тренеров |
| Руководитель (RP) | всех младше себя на своём проекте | всех младше себя |
| Администратор (ADM) | всех, кроме IT и администраторов | всех, кроме IT и администраторов |
| IT | всех | всех |
| Суперпользователь | всех | всех и может удалить запись навсегда |

Старший и руководитель видят только те проекты, где работают сами.
Свою должность они в списке подчинённых не видят.

## Важно про пароли

Сейчас пароли специально хранятся и показываются в открытом виде.
Это нужно для проверки работы программы.

Отчёты тоже содержат пароли. Не передавайте их посторонним.
После проверки старые отчёты можно удалить.

## Запуск как службу

Если нужно, чтобы сайт поднимался сам при включении сервера,
в папке `deploy` есть два образца:

- `crm.service` — для Linux;
- `nssm.txt` — для Windows.

Инструкция прямо в файлах. Там же написано, какие настройки выставить
для доступа с других компьютеров.

## Если что-то пошло не так

**Программа говорит, что не нашла настроек.**
Запустите `install.py` ещё раз или скопируйте `config.example.ini`
в `config.ini` и заполните его.

**Программа говорит, что не нашла файл с паролями.**
Положите `for_db.xlsx` в папку с программой или укажите другой путь
в настройках.

**Список не открывается.**
Проверьте, что сайт запущен (пункт 3 меню) и окно не закрыто.
Посмотрите файл `logs/web.log`.

**Страницы не переключаются.**
Обновите страницу в браузере. Если не помогло, нажмите пункт 5 меню.

**Пароль не обновился.**
Откройте отчёт `report_errors_...txt`. Там написано, какая запись вызвала
вопрос. Чаще всего не совпадает имя, фамилия или логин.

**Обновление не начинается.**
Возможно, оно уже идёт в другом окне. Дождитесь окончания.

**Предупреждение про проверки данных при загрузке Excel.**
Такое сообщение больше не показывается. Если оно всё же появилось,
напишите, из какого файла оно пришло.
